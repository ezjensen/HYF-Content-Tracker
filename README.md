# HYF Content Tracker

Huntley Youth Football's posts, emails and reminders: schedule, assignees, notes, tags and search.

- Static site (plain HTML/JS), hosted on GitHub Pages.
- Data and logins: Supabase (tables prefixed `hyf_`). Access requires an approved account.
- `config.js` holds only the public project URL and publishable key. Never put a secret key in this repo.
